# Изменения в подписке - Удаление годового тарифа

## Дата: 8 октября 2025

## Что было изменено

### 1. Страница подписки (`src/app/[locale]/(dashboard)/dashboard/subscription/page.tsx`)

**До:**
- Две кнопки: месячная и годовая подписка
- Состояние загрузки: `useState<null | 'monthly' | 'yearly'>(null)`
- Обработчик с параметром типа: `handleSubscribe(type: 'monthly' | 'yearly')`

**После:**
- Одна кнопка: только месячная подписка (5 510 тг/месяц)
- Состояние загрузки: `useState<boolean>(false)`
- Обработчик без параметров: `handleSubscribe()`

### 2. Стили (`page.module.scss`)

**До:**
- Кнопки шириной 300px каждая
- Разные цвета для первой и второй кнопки
- Специфичные стили для `:first-child` и `:last-child`

**После:**
- Одна кнопка шириной 400px
- Единый цвет (#1C2C52)
- Добавлен эффект при наведении:
  - Трансформация: `translateY(-2px)`
  - Тень: `box-shadow: 0 4px 12px rgba(28, 44, 82, 0.3)`
- Состояние disabled с прозрачностью 0.6

## Визуальные изменения

### Текущий вид
- **Одна кнопка** по центру страницы
- **Размер:** 400px × 60px (на десктопе)
- **Цвет:** Темно-синий (#1C2C52)
- **Текст:** "Подключить за 5 510 тг/месяц"
- **Эффекты:**
  - При наведении: поднимается на 2px + тень
  - При загрузке: прозрачность 60% + курсор not-allowed

### Адаптивность
- На мобильных устройствах (≤768px): кнопка занимает 100% ширины (максимум 350px)

## Логика работы

1. Загружаются все доступные тарифные планы с API
2. Выбирается план с `duration_months === 1` (месячная подписка)
3. При клике на кнопку:
   - Устанавливается `loading = true`
   - Вызывается API `lawyerApi.subscribe(plan.id, true)`
   - Если получена ссылка на оплату - редирект
   - Иначе показывается уведомление об успехе
4. В случае ошибки - показывается toast с ошибкой

## API запросы

### GET - Получение тарифов
```typescript
const res = await lawyerApi.getAllSubscriptionPlans()
// Возвращает массив планов с полями: id, duration_months, price и др.
```

### POST - Оформление подписки
```typescript
const res = await lawyerApi.subscribe(planId, autoRenew)
// Параметры:
// - planId: ID тарифного плана
// - autoRenew: true (автопродление)
// Возвращает: { link: string } - ссылка на оплату
```

## Тестирование

Для проверки изменений:

1. Перейдите на `/dashboard/subscription`
2. Убедитесь, что отображается только одна кнопка
3. Проверьте текст: "Подключить за 5 510 тг/месяц"
4. Наведите на кнопку - должен быть эффект поднятия и тени
5. Кликните на кнопку - должна начаться загрузка
6. После загрузки должен произойти редирект на страницу оплаты

## Причина изменений

Упрощение выбора для пользователей - оставлен только один доступный тарифный план (месячная подписка). Годовая подписка больше не предлагается.
